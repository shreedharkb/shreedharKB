## Projects

- **[LexFind](https://github.com/shreedharkb/LexFind)** — agentic legal research over a large corpus. A LangGraph agent routes each query to corpus search, document Q&A or chat; hybrid BM25 and dense retrieval fused with RRF, with a self-correcting retrieval loop.
  `FastAPI · React · Qdrant · pgvector · Celery · RabbitMQ`

- **[Speechify](https://github.com/shreedharkb/Speechify)** — quiz platform that grades spoken and free-text answers semantically rather than by exact match, with grading decoupled onto queues.
  `Node.js · React · Sentence-BERT · Whisper · Redis · Docker`

- **[FinOS](https://github.com/shreedharkb/FinOS)** — personal finance dashboard that turns receipt photos into categorised, budgeted transactions and automates the reporting around them.
  `Next.js · PostgreSQL · Prisma · Gemini · Inngest`
